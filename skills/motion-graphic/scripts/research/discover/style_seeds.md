# Style seeds: where to start looking

Starting accounts for each style in the menu in `references/intake.md`. These are seeds, not endorsements: brands change their film style, stop posting, or rename accounts. **Verify still active** before you use any of them: open the account, check it has posted a film in this style in the last 12 months, and drop it if not. Add the owner's own references first; these fill the gaps.

Platform handles are left out on purpose, because they change. Find them with a web search or on the brand's site.
